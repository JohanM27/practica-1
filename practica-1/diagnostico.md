# Diagnóstico de Code Smells

## Problemas identificados
1. Nombres de variables poco descriptivos.
2. Uso del número mágico 86400.
3. Falta de claridad en la intención del código.

## Refactorización
Se reemplazaron los nombres ambiguos por nombres descriptivos
y se extrajo el número mágico a una constante.

## Resultado
El código mantiene su comportamiento original y mejora
su legibilidad y mantenibilidad.
